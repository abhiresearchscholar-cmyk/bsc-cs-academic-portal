Data Structure and Algorithms

A course focused on core data structures, searching techniques, memory-related concepts, trees, file systems, and algorithmic problem-solving foundations.

Core Course

Course Introduction

This course introduces students to the main ways data is organized, stored, searched, and processed. It builds understanding of stacks, queues, linked lists, trees, searching methods, and storage-related structures used in computing.

Third Year

Learning Objectives

Students will learn fundamental data structures, search algorithms, memory and storage concepts, and file organization techniques that support efficient software design and analysis.
