Third Year · Core Course

Software Engineering

A course focused on software process models, requirements engineering, design, configuration management, metrics, estimation, testing, and maintenance concepts.

Core Course

Course Introduction

This course helps students understand how software is planned, designed, measured, tested, and maintained in a disciplined way. The material covers the full development lifecycle from requirements to maintenance and tool support.

Third Year

Learning Objectives

Students will learn software development models, requirements engineering, design approaches, configuration management, software metrics, project estimation, and testing strategies used in real software projects.
