Third Year · Core Course

Operating System

A course focused on operating system fundamentals, process management, CPU scheduling, memory management, virtual memory, shell basics, and scripting concepts.

Core Course

Course Introduction

This course helps students understand how operating systems manage hardware, processes, memory, files, and user interaction. The material moves from foundational concepts to scheduling, memory techniques, and shell-based work.

Third Year

Learning Objectives

Students will learn operating system services, system calls, process management, scheduling algorithms, memory management, virtual memory, and shell scripting concepts used in system-level computing.
