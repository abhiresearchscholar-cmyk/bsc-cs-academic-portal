00 Picking up where we left off

Every computer has five basic parts.

Remember the Input → Process → Output → Storage cycle from Lecture 01? Today we give each stage a name and a job description. Every computer system — a supercomputer, your laptop, a smartwatch — is built from exactly five basic components.

01 The doors in and out

Input Unit and Output Unit: the two doors.

The Input Unit is any hardware that lets data enter the computer, converting your action (a keypress, a tap, a sound) into binary the machine can process. The Output Unit does the reverse: it takes the computer's binary result and turns it into something you can see, hear, or hold. Click a device to see which side it belongs to.

04 The CPU's own tiny notepad

Why does the CPU need its own private memory?

Registers are extremely small, extremely fast storage locations built directly into the CPU itself — holding only the handful of values the CPU is working with right this instant. They're far faster than RAM, but there are only a few of them, each holding just one small value at a time. Click a value in memory to load it into a register.

05 How the CPU actually "runs"

Fetch. Decode. Execute. Repeat — billions of times a second.

A program is just a list of tiny commands stored in memory. The CPU works through that list one command at a time, in an endless three-step loop called the instruction cycle:

What is an "instruction set"? Every CPU understands only a fixed vocabulary of basic commands — like "add these two numbers" or "move this value" — called its instruction set. It's the complete list of every single thing that model of CPU knows how to do. Different CPU families (which you'll meet shortly) can have different instruction sets, which is one reason software built for one type of chip doesn't always run on another.
TAKEAWAY · The instruction cycle (Fetch → Decode → Execute) repeats endlessly. The instruction set is the fixed vocabulary of commands a CPU understands.
06 How fast is "fast"?

Clock speed, and why more cores can mean more speed.

A CPU has an internal "clock" ticking at an incredibly steady rate — every tick, it can start a new step of work. This rate is called the clock speed, measured in GHz (gigahertz) — billions of ticks per second. Try different speeds below.

Interactive · the CPU clock
Roughly 1 billion ticks/second at this speed

A single core can only work on one thing per tick. Multi-core processors pack several independent "workers" (cores) onto one chip, so multiple tasks can run at the same time.

TAKEAWAY · Clock speed (GHz) = how many steps per second one core can take. More cores = more tasks handled at once, not a faster single task.

08 Two philosophies of chip design

RISC vs. CISC: simple bricks, or an all-in-one tool?

Beyond brands, CPUs also differ in design philosophy — specifically, how big and complex their instruction set is.

RISC

Reduced Instruction Set Computer. Uses a small number of simple instructions, each doing one basic job, executed very quickly. Programs need more instructions overall, but each one is fast and predictable.

Used by: ARM chips (most phones), Apple's M-series chips

CISC

Complex Instruction Set Computer. Uses a larger set of more powerful instructions, where a single instruction can perform several steps at once. Fewer instructions needed per program, but each one is more complex.

Used by: Intel and AMD's x86 chips (most laptops/desktops)
🧱
Think of building furniture. RISC is like simple Lego bricks — each piece does one small thing, but you snap together many of them quickly and predictably. CISC is like a Swiss Army knife — fewer tools overall, but each one is a powerful multi-step gadget in itself.
TAKEAWAY · RISC = many simple, fast instructions (ARM, Apple Silicon). CISC = fewer, more powerful, complex instructions (Intel, AMD x86).
