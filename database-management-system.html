Database Management System

A course focused on databases, DBMS architecture, data models, ER modeling, SQL, relational algebra, normalization, and relational keys.

Core Course

Course Introduction

This course helps students understand how data is organized, modeled, queried, and maintained in modern database systems. The material covers the progression from database basics to relational concepts and normalization.

Second Year

Learning Objectives

Students will learn database fundamentals, DBMS architecture, ER modeling, SQL, relational algebra, relational constraints, normalization, and key concepts used in database design.
